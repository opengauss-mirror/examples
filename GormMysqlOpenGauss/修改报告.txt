二、评审意见处理情况

1. DSN 校验

将自定义字符串判断改为调用 go-sql-driver/mysql 的 driver.ParseDSN，并检查 cfg.Net == "tcp"。现在能够拒绝非法 DSN、Unix socket DSN 和非 TCP 网络配置。

涉及文件：
GormMysqlOpenGauss/internal/config/config.go

2. DSN 参数追加

修复 ensureParam 的部分参数名误判问题。现在只比较查询参数等号前的完整键名，可以保留用户显式设置的 parseTime=false、loc=UTC 等参数，不会把 time 错误识别为 parseTime。

新增测试覆盖完整参数名匹配和非法 DSN 场景。

涉及文件：
GormMysqlOpenGauss/internal/config/config.go
GormMysqlOpenGauss/internal/config/config_test.go

3. 连接超时和重复 Ping

将 30 秒 context 提前到配置读取和数据库打开之前创建，并在 gorm.Open 中设置 DisableAutomaticPing=true。数据库连通性由后续显式 HealthCheck 完成，避免自动 Ping 和 HealthCheck 重复执行。

涉及文件：
GormMysqlOpenGauss/cmd/gorm-opengauss/main.go
GormMysqlOpenGauss/internal/db/opengauss.go

4. schema.table 限定表名

修复 ColumnTypes 和 GetIndexes 在传入 schema.table 时拆分后使用裸表名的问题。现在保留 qualifiedTable 用于样本查询，只将拆分后的 schema 和 table 用于 information_schema 元数据过滤，避免查询当前 schema 中的同名表。

涉及文件：
GormMysqlOpenGauss/internal/db/opengauss.go

5. OPENGAUSS_DATABASE 使用说明

README 补充说明：OPENGAUSS_DATABASE 和 DSN 中斜杠后的名称填写目标 schema，例如 gorm_test；物理 B 兼容库由 Dolphin 服务端配置选择。运行 migrate 前需要确认 schema 已创建，并授予连接用户 USAGE、CREATE 等权限。

涉及文件：
GormMysqlOpenGauss/README.md
