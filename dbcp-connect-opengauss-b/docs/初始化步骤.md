# 初始化步骤

本文说明如何为 DBCP 示例准备 openGauss B 兼容数据库。openGauss 应使用包含 Dolphin
插件的安装包或转测包。

## 前置条件

- openGauss 实例已使用 `gs_initdb` 初始化。
- 当前用户可以执行 `gs_ctl` 和 `gsql`。
- 已设置 `PGDATA` 和 `GAUSSLOG`。

## 1. 配置 Dolphin

编辑 `$PGDATA/postgresql.conf`：

```ini
shared_preload_libraries = 'dolphin'
enable_dolphin_proto = on
dolphin_server_port = 3308
dolphin.default_database_name = 'proto_test_db'
```

重启实例并确认两个协议端口均正常：

```bash
gs_ctl restart -D "$PGDATA" -Z single_node -l "$GAUSSLOG/restart.log"
gs_ctl query -D "$PGDATA"
ss -tlnp | grep -E '5432|3308'
```

## 2. 配置客户端认证

编辑 `$PGDATA/pg_hba.conf`。以下示例只允许本机连接：

```ini
local   all all              trust
host    all all 127.0.0.1/32 sha256
host    all all ::1/128      sha256
```

远程连接时应将地址改为实际客户端所在的受限网段。修改后重新加载配置：

```bash
gs_ctl reload -D "$PGDATA"
```

## 3. 初始化数据库

1. 将 `src/main/resources/create_b_database.sql` 中的 `<DBCP_PASSWORD>` 替换为测试密码。
2. 使用相同密码配置 `src/main/resources/dbcp.properties`。
3. 依次执行建库和建表脚本：

```bash
gsql -d postgres -h "$PGDATA" -p 5432 \
  -f src/main/resources/create_b_database.sql
gsql -d proto_test_db -h "$PGDATA" -p 5432 \
  -f src/main/resources/init.sql
```

第一个脚本创建 B 兼容库 `proto_test_db`、schema `mysql_test_db` 并设置 MySQL native
密码；第二个脚本创建 `user` 表并写入三条初始数据。

如果 Spring Boot 使用非表 owner 的专用业务账号，需额外授予 schema、表和自增序列权限：

```sql
GRANT ALL ON SCHEMA mysql_test_db TO <DBCP_USER>;
GRANT ALL ON ALL TABLES IN SCHEMA mysql_test_db TO <DBCP_USER>;
GRANT ALL ON ALL SEQUENCES IN SCHEMA mysql_test_db TO <DBCP_USER>;
```

## 4. Spring Boot 链路验证

完成初始化后，在工程目录执行：

```bash
DBCP_PASSWORD='实际密码' mvn spring-boot:run
```

程序会由 Spring Boot 创建 DBCP `BasicDataSource`，通过 `JdbcTemplate` 查询业务表，
再用 `TransactionTemplate` 分别验证提交和回滚。日志中的数据源类型必须为
`org.apache.commons.dbcp2.BasicDataSource`，否则说明依赖或配置未按文档设置。

## 5. 低层测试和 JDBC 示例

```bash
mvn clean test -Ddbcp.password="$DBCP_PASSWORD"
mvn exec:java -Dexec.mainClass=org.opengauss.DbcpConnectDemo
```

全量测试应输出：

```text
Tests run: 46, Failures: 0, Errors: 0, Skipped: 0
BUILD SUCCESS
```
